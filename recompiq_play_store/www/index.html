Google Play Store Production Architecture (AAB)

Option A: Capacitor Native Android (Recommended)

Packages this app as a native offline Android binary (.aab) with zero hosting required. 

npm install
npx cap add android
npx cap sync android
npx cap open android
Option B: Trusted Web Activity (Bubblewrap TWA)

Wraps a hosted HTTPS PWA into a Google Play Store app-release-bundle.aab. 

npm i -g @bubblewrap/cli
bubblewrap init --manifest=/manifest.webmanifest
bubblewrap build
